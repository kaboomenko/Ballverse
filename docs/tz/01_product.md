# 01. Продукт: видение, аудитория, сценарии, состав релиза

## 1.1. Видение

Ballverse — «карманная студия satisfying-роликов». Пользователь открывает приложение, за 5 секунд видит живую физическую симуляцию, за минуту настраивает её под себя, за две минуты склеивает со своим видео и публикует ролик.

Ballverse не конкурирует с CapCut как монтажный инструмент и не конкурирует с Helix Jump как гиперказуальная игра. Ценность продукта в связке: **уникальный зрелищный контент (симуляция) + минимальный монтаж (split-screen) + экспорт в формате коротких видео**. Ни игры-аналоги, ни видеоредакторы эту связку не дают.

### Столпы продукта

| # | Столп | Что это значит для решений |
|---|---|---|
| С1 | **Зрелищность с первого кадра** | Любая симуляция «из коробки» должна выглядеть как вирусный ролик. Плохих настроек по умолчанию нет. Рандомизация выдаёт только хорошие варианты (§2.4). |
| С2 | **Минуты, а не часы** | Путь «открыл → опубликовал» укладывается в 3 минуты для нового пользователя и в 1 минуту для опытного. Каждый лишний экран обоснован. |
| С3 | **Контроль без сложности** | Простые ползунки на виду, тонкие настройки спрятаны. Можно задать победителя и длительность — то, что нужно автору. |
| С4 | **Экспорт безупречен** | Готовый ролик всегда плавный (ровно 30/60 FPS), без рывков и артефактов, даже на слабом телефоне. Это главное техническое обещание (§7.5). |
| С5 | **Честная монетизация** | Цены и наборы постоянные, никаких таймеров. Реклама не ломает творческий процесс. Если реклама не загрузилась, пользователь не теряет работу. |

## 1.2. Целевая аудитория и персоны

| Персона | Кто | Чего хочет | Что делает в Ballverse | Платит за |
|---|---|---|---|---|
| **Автор** (основная) | 16–30 лет, ведёт TikTok/Shorts/Reels, 100–100 000 подписчиков | Быстрый оригинальный контент, рост охватов, форматы «какой шар победит», «реакция» | Генерирует симуляцию, задаёт победителя, склеивает со своим лицом (split-screen), экспортирует 3–10 роликов в неделю | Отключение рекламы перед экспортом и водяного знака (релиз 1); новые режимы (после релиза) |
| **Зритель-залипатель** | 13–35 лет, смотрит satisfying-видео | Медитативное залипание, «ещё один запуск» | Запускает режимы, крутит параметры, смотрит, иногда сохраняет клип | Отдельные режимы, отключение межстраничной рекламы |
| **Игрок** | 12–40 лет, любитель простых физических игр | Короткие игровые сессии | Играет в интерактивные режимы (релиз 1 — Хеликс-дроп; позже Пег-дроп, Разрушение, Лабиринт) | Отключение рекламы; режимы (после релиза) |
| **Мем-мейкер** | 14–25 лет, делает ролики «для своих» | Шутки с именами друзей, «кто выбывает первым» | Вписывает имена в гонку/выбывание, экспортирует в чат | Редко, рекламой |

**Возрастная политика:** приложение позиционируется как **13+** (возрастной порог TikTok/Instagram/YouTube для аккаунтов). В Google Play целевая аудитория указывается «13 лет и старше», приложение не участвует в программе Families. Подробности и риски — §10 и вопрос В14 в `../open_questions.md`.

## 1.3. Главный цикл

```
 ┌──────────────┐   ┌──────────────┐   ┌───────────────┐   ┌──────────────┐   ┌──────────────┐
 │ Выбор режима │ → │ Симуляция    │ → │ Клип          │ → │ Студия       │ → │ Экспорт и    │
 │ (галерея)    │   │ запуск,      │   │ (каждый запуск│   │ split-screen,│   │ публикация   │
 │              │   │ настройка,   │   │ уже записан)  │   │ текст, звук, │   │ MP4 9:16     │
 │              │   │ 🎲 генерация │   │               │   │ предпросмотр │   │              │
 └──────────────┘   └──────────────┘   └───────────────┘   └──────────────┘   └──────────────┘
        ↑                  │  «Ещё раз» (игровой мини-цикл, interstitial каждые 3 игры)   │
        └──────────────────┴───────────────────────────────────────────────────────────┘
```

- **Игровой мини-цикл (30–90 с):** запуск → наблюдение или игра → результат → «Ещё раз» / «🎲». Здесь работает interstitial-реклама.
- **Творческий цикл (1–5 мин):** клип → студия → экспорт. Здесь работает rewarded-реклама перед экспортом.
- **Мета-цикл (дни):** проекты, повторный экспорт, новые пресеты (Remote Config); после релиза 1 — новые режимы волнами roadmap (бесплатные и покупка).

### Ключевая механика «каждый запуск уже записан»

Пользователю не нужно заранее нажимать «Запись». Каждый запуск симуляции автоматически сохраняется как **реплей** (сид, параметры, ввод; см. §7.4). Когда получился удачный запуск, пользователь нажимает «В видео», и этот запуск становится клипом. Неудачный запуск ничего не стоит: реплей весит килобайты и удаляется, если его не использовали. Это снимает главную боль записи экрана: «самое интересное случилось, а я не записывал».

  - HEVC-экспорт (меньше размер файла);

## 1.6. Глоссарий

| Термин | Код | Определение |
|---|---|---|
| Режим | `Mode`, `M01`–`M15` | Тип физической симуляции со своими правилами, генератором и параметрами (§2). |
| Симуляция | `Sim` | Один запуск режима с конкретными параметрами и сидом. |
| Сид | `seed` | 64-битное число, определяющее всю случайность запуска. Один сид + одни параметры + один ввод = один и тот же результат на одном устройстве и сборке. |
| Пресет | `Preset` | Именованный набор параметров режима («Неон-хаос», «Медитация»). |
| Реплей | `Replay`, файл `.bvr` | Запись запуска: сид, параметры, ввод, контрольные хэши, события. Компактный источник истины (§7.4). |
| Поток рендера | файл `.bvs` | Покадровое визуальное состояние запуска (позиции, углы, цвета). Производный кэш, из которого рисуются предпросмотр и экспорт; восстанавливается из реплея (§7.4). |
| Клип | `Clip` | Реплей, отобранный пользователем для студии, с обрезкой по времени. |
| Студия | `Studio` | Встроенный видеоредактор (§3). Название выбрано, чтобы не путать с редактором Unity. |
| Раскладка | `Layout`, `L1`–`L5` | Способ расположения симуляции и видео пользователя в кадре (§3.3). |
| Проект | `Project` | Клип + видео пользователя + настройки студии. Сохраняется локально (§3.9). |
| Режиссёр | `Director` | Механизм подбора сида под цель: длительность, победитель, драматичный финал (§2.5). |
| Завершённая игра | `GameCompleted` | Событие, которое считает interstitial-реклама (§5.3.2). |
| Медиамост | `MediaBridge` | Нативный модуль декодирования, кодирования и записи видео на iOS и Android (§7.5). |
| Тир устройства | `Tier A/B/C` | Класс производительности устройства (§8.1). |
