# Ballverse

Мобильное приложение для iOS и Android: **физические мини-игры + генератор залипательных симуляций + видеоредактор**. За несколько минут пользователь создаёт вертикальный ролик для TikTok, YouTube Shorts или Instagram Reels: запускает симуляцию, настраивает или генерирует её одной кнопкой, склеивает со своим видео в split-screen и экспортирует MP4 9:16. В первом релизе — 3 бесплатных режима: **Ring Escape** (побег из вращающихся колец), **Geometry Bounce** (шары во вращающихся многоугольниках), **Helix Drop** (падение сквозь башню вращающихся платформ); ещё 12 режимов — в roadmap.

> **Статус (2026-10-18):** ТЗ обновлено под релиз 1 (решения Р18–Р27). Идёт 7-дневный план до устанавливаемой сборки на телефоне владельца (2026-10-18 → 2026-10-24, [§11.2](docs/tz/11_roadmap.md)): ядро `Ballverse.Core` (11 модулей) сливается, решатель `Core.Sim` и логика трёх режимов — в работе, Unity-слой собирается только в CI (GameCI) после добавления секретов лицензии Unity. Действия владельца на день 1 — вопросы 🔴 В21, В23 в [`docs/open_questions.md`](docs/open_questions.md) и секреты Unity в GitHub. Текущие задачи — [`docs/dev/backlog.md`](docs/dev/backlog.md).

## Ключевые решения в одном экране

| Тема | Решение |
|---|---|
| Продукт | Игра + генератор симуляций + видеоредактор. Цель — готовый ролик за минуты |
| Платформы | iOS 16+ и Android 8.0+, полный паритет. Только портрет. Bundle ID — временно `com.ballverse.app` |
| Режимы релиза 1 | 3, все **бесплатные** (Р18): M01 Ring Escape (`ring_escape`), M02 Geometry Bounce (`geometry_bounce`), M05 Helix Drop (`helix_drop`). Референсы — только механики, арт и звуки свои (Р27); название «Helix Drop» проверяется до публикации (В22) |
| Roadmap | 12 режимов волнами после релиза: M03, M04, M07 → M08, M10, M13, M14 → (Box2D v3) M06, M09, M11, M12 → M15 |
| Генерация | 🎲 прогоняет 8–24 кандидата в фоне быстрее реального времени и выбирает самый зрелищный; можно задать длительность и победителя (подбирается сид, физика честная) |
| Физика | Релиз 1: собственный детерминированный решатель на чистом C# `Ballverse.Core.Sim` (Р23) — тестируется в контейнере; параметры режимов связаны правилами валидации (проходимость, упаковка, конверт скоростей, §2.9). Box2D v3 — для будущих режимов со стопками и соединениями |
| Запись | Каждый запуск автоматически пишется как реплей (килобайты). Экспорт — офлайн-рендер из записи: всегда ровные 30/60 FPS в 720p/1080p, даже на слабом телефоне |
| Студия | 5 раскладок split-screen с регулируемой пропорцией, обрезка и синхронизация, текст, микширование звука, зоны интерфейса площадок. Предпросмотр и экспорт рисует один компоновщик |
| Экспорт | MP4, H.264 High + AAC, 9:16, 1080p/60 FPS (и 720p/30), до 180 с; сегменты по 2 с с возобновлением; аппаратные кодеки через нативный MediaBridge (релиз 1: iOS ObjC++, Android Java, кадры RGBA), без FFmpeg |
| Стек | Unity 6 LTS + C#, URP 2D, UI Toolkit + собственный стеклянный материал, Unity IAP, AdMob + UMP, Firebase. Unity-код компилируется только в CI (GameCI) |
| Монетизация | Релиз 1: rewarded перед экспортом, interstitial после каждых 3 завершённых игр; магазин — Remove Export Ads $6,99, Remove Interstitial Ads $5,99, No Ads $8,99; водяной знак «Made with Ballverse» снимает No Ads (или обе покупки рекламы). Товары режимов, All Modes, Ultimate — с выпуском режимов. Без подписок и таймеров; реклама никогда не отнимает готовый ролик |
| Бэкенд | Нет своего сервера в 1.0: всё локально, Firebase для аналитики и конфигурации |
| Сроки | Устанавливаемая сборка релиза 1 на телефоне владельца — 2026-10-24 (7 дней); публикация в сторах — +2–4 недели; полный каталог из 15 режимов — ≈ 3–4 месяца после релиза 1 |
