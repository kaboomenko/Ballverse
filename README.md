# Ballverse

Мобильное приложение для iOS и Android: **физические мини-игры + генератор залипательных симуляций + видеоредактор**. За несколько минут пользователь создаёт вертикальный ролик для TikTok, YouTube Shorts или Instagram Reels: запускает одну из 15 симуляций (кольца, гонки шариков, битвы, лабиринты, разрушение…), настраивает или генерирует её одной кнопкой, склеивает со своим видео в split-screen и экспортирует MP4 9:16.

> **Статус:** техническое задание v1.0 (2026-10-18). Кода пока нет. Следующий шаг — ответы владельца на вопросы 🔴 в [`docs/open_questions.md`](docs/open_questions.md) и спайки этапа 0 ([§11](docs/tz/11_roadmap.md)).

## Ключевые решения в одном экране

| Тема | Решение |
|---|---|
| Продукт | Игра + генератор симуляций + видеоредактор. Цель — готовый ролик за минуты |
| Платформы | iOS 16+ и Android 8.0+, полный паритет. Только портрет |
| Режимы | 15: бесплатно M01 «Побег из колец», M02 «Растущий шар», M03 «Гонка шариков», M04 «Пег-дроп», M05 «Спираль»; платно ($1,99) — битвы, выбывание, война цветов, умножение, лабиринт, разрушение, цепная реакция, маятники, орбиты, жидкость и песок |
| Генерация | 🎲 прогоняет 8–24 кандидата в фоне быстрее реального времени и выбирает самый зрелищный; можно задать длительность и победителя (подбирается сид, физика честная) |
| Запись | Каждый запуск автоматически пишется как реплей (килобайты). Экспорт — офлайн-рендер из записи: всегда ровные 30/60 FPS в 720p/1080p, даже на слабом телефоне |
| Студия | 5 раскладок split-screen с регулируемой пропорцией, обрезка и синхронизация, текст, микширование звука, зоны интерфейса площадок. Предпросмотр и экспорт рисует один компоновщик |
| Экспорт | MP4, H.264 High + AAC, 9:16, 720p/1080p, 30/60 FPS, до 180 с; аппаратные кодеки через нативный MediaBridge, без FFmpeg |
| Стек | Unity 6 LTS (≥ 6.3) + C#, URP 2D, Box2D v3 (`LowLevelPhysics2D`), UI Toolkit + собственный стеклянный материал, Swift/Kotlin/C++ для видео, Unity IAP, AdMob + UMP, Firebase |
| Монетизация | Разовые покупки по брифу (режим $1,99 … Ultimate $11,99), rewarded перед экспортом, interstitial после каждых 3 завершённых игр; водяной знак «Made with Ballverse» убирается только Ultimate; без подписок и таймеров; реклама никогда не отнимает готовый ролик |
| Бэкенд | Нет своего сервера в 1.0: всё локально, Firebase для аналитики и конфигурации |
| Сроки | ≈ 6–7 месяцев до глобального запуска; первые 3 недели — спайки по главным рискам |
