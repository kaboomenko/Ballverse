# 04. Интерфейс и UX

## 4.1. Принципы

1. **Контент в центре.** Симуляция и предпросмотр занимают максимум экрана. Управление плавает поверх контента на «стеклянных» панелях и прячется, когда не нужно.
2. **Одно главное действие на экране.** Галерея — выбрать режим; симуляция — 🎲 и «В видео»; студия — «Экспорт».
3. **Тап, а не меню.** Частые действия — одним тапом, редкие — в раскрываемых группах настроек.
4. **Одинаково на iOS и Android.** Собственный визуальный язык Ballverse, а не копия системных компонентов. Системными остаются только выбор видео, «Поделиться», покупки, диалоги согласия и разрешений.
5. **Только портретная ориентация** (приложение и все экраны). Ландшафт не поддерживается в 1.0.

## 4.3. Экраны

### Первый запуск (US-01)

- Холодный старт → сразу **экран симуляции M01** с запущенным пресетом «Классика». Без регистрации, без карусели «добро пожаловать», без запроса разрешений.
- Поверх — 3 ненавязчивые подсказки по очереди (каждая исчезает от любого действия): «Нажми 🎲 — новая симуляция», «Крути настройки здесь», «Понравилось? Сделай видео».
- Квест первого ролика (необязательный, сворачиваемый): ✓ запусти симуляцию → ✓ сгенерируй свою → ✓ экспортируй видео. После выполнения — короткий праздничный экран и предложение попробовать платный режим (без давления, кнопка «Позже» равнозначна по размеру).
- Согласие UMP показывается **до** инициализации рекламы, только в регионах, где требуется (ЕЭЗ, Великобритания, Швейцария, штаты США с законами о приватности — по данным UMP). Запрос ATT (iOS) — **не при первом запуске**, а перед первым показом рекламы, с предварительным собственным экраном-объяснением (§5.6).

### Галерея режимов («Режимы»)

- Сетка 2 колонки, 15 карточек. Карточка: **зацикленное видео-превью 3–4 с** (заранее отрендеренный ролик H.264 ≈ 200–300 КБ, итого ≤ 5 МБ в сборке), название, значки «Интерактив», «Победитель», «Новое».
- Платная карточка: замок, цена в локальной валюте из магазина, кнопка превью доступна (§5.2 — пробный просмотр).
- Сверху — баннер **All Modes Bundle** (если не куплен) с постоянной ценой и экономией («10 режимов за $4,99 вместо $19,90»). Никаких таймеров (Р6).
- Сортировка по умолчанию: бесплатные → купленные → платные; порядок внутри групп управляется Remote Config.

### Экран симуляции

- Симуляция на весь экран, от края до края (с учётом вырезов камеры, контент арены внутри безопасной зоны).
- **Верхняя стеклянная панель:** «Назад», название режима и пресета (тап — лист пресетов), шестерёнка настроек.
- **Нижняя плавающая стеклянная панель:** ⟲ «Ещё раз» · ⏯ пауза/пуск · **🎲** (крупная, акцентная) · ⚡ скорость · **«В видео»** (акцентная кнопка с иконкой ножниц/плёнки).
- Панели исчезают через 2 с во время `Running` (для интерактивных режимов) и плавно появляются по тапу вне игровой зоны. Для автоматических режимов панели видны, но полупрозрачны (40%).
- **Лист настроек** — нижний лист на 50% / 90% высоты (два положения), симуляция остаётся видна сверху и реагирует на изменения в реальном времени. Группы — сегментированный переключатель.
- **Генерация 🎲:** короткое нажатие — генерация с текущими настройками режиссёра; долгое нажатие — мини-лист «Стиль» и «Длительность».
- **Экран результата** — стеклянная карточка поверх последнего кадра: победитель/счёт/время, «Ещё раз», «🎲», «В видео», лента 5 предыдущих запусков.

### Студия

- Верх: предпросмотр 9:16 (~60% высоты), под ним кнопки ⏯, время, полноэкранный режим, отмена/повтор.
- Середина: таймлайн (дорожки S, V, текст, музыка) с миниатюрами.
- Низ: стеклянная таб-панель инструментов **Макет · Видео · Симуляция · Текст · Звук**; содержимое инструмента — в нижнем листе.
  - *Макет:* 5 раскладок (иконки), ползунок пропорции, «поменять местами», разделитель, отступы, скругления, «Зоны интерфейса».
  - *Видео:* импорт / замена, обрезка, поворот, зеркало, заполнение, громкость.
  - *Симуляция:* обрезка, скорость, слоу-мо финала, поведение после конца, смена звукового пакета, возврат к режиму («Перегенерировать» — открывает экран симуляции с теми же настройками).
  - *Текст:* шаблоны, добавить, стиль, время.
  - *Звук:* громкости дорожек, музыка, нормализация.
- Правый верх: **«Экспорт»** — главная акцентная кнопка.
- Если видео пользователя ещё не добавлено, слот V показывает пунктирную рамку «+ Добавить своё видео» и переключатель «Без видео» (раскладка L4).

### Проекты

- Вкладки **Проекты** / **Клипы**. Сетка карточек с обложками. Долгое нажатие — контекстное меню. Пустое состояние — анимация и кнопка «Сделать первый ролик».

### Магазин

- Сверху — **Ultimate Bundle** (все режимы + без рекламы), затем **All Modes**, **No Ads**, затем отдельные покупки рекламы, затем сетка режимов.
- Каждая карточка: что входит (списком), постоянная цена, экономия относительно покупки по отдельности, состояние «Куплено ✓» / «Частично куплено».
- Внизу: «Восстановить покупки», ссылки на условия и политику конфиденциальности.
- Подробная логика — §5.

### Настройки

Звук и вибрация · Качество графики (Авто / Высокое / Экономное) · Язык · Тема интерфейса (Системная / Тёмная / Светлая) · Доступность (§4.8) · Водяной знак по умолчанию · Автосохранение в галерею · Хранилище · Восстановить покупки · Конфиденциальность (повторный вызов UMP, ATT-статус) · Оценить приложение · Обратная связь (почта с автоматически приложенной диагностикой без персональных данных) · О приложении и лицензии сторонних компонентов.

## 4.4. Визуальный язык

- **Тема интерфейса по умолчанию — тёмная** (неоновые симуляции выглядят лучше на тёмном), светлая доступна и следует системной настройке, если выбрано «Системная».
- **Сетка:** базовый шаг 4 pt, отступы 16/24 pt, минимальная зона касания 44×44 pt.
- **Типографика:** один семейный шрифт интерфейса с кириллицей и латиницей (например, Inter или Manrope, лицензия OFL), 5 размеров (12/14/17/22/34), поддержка увеличения текста до 130% без поломки вёрстки.
- **Цвет:** нейтральные стеклянные поверхности + один акцентный цвет бренда (градиент «электрик» сине-фиолетовый — уточняется в брендбуке, вопрос В16) для главных действий.
- **Иконки:** собственный набор в едином стиле (контур 2 pt, скруглённые концы), SVG → векторные спрайты.
- **Анимации:** пружинные (spring) переходы 250–350 мс; все анимации уважают «Уменьшить движение» (§4.8).

## 4.5. Liquid Glass (Требование 13)

**Liquid Glass** — визуальный язык Apple с iOS 26: полупрозрачные материалы с размытием, преломлением фона и бликами по краям, которые «плавают» над контентом. Нативный материал доступен только в SwiftUI/UIKit на iOS 26+. Ballverse рисует интерфейс движком (§6), поэтому реализует **собственный материал `BallverseGlass`**, вдохновлённый Liquid Glass, одинаковый на iOS и Android.

### Где применяется (уместно)

| Элемент | Почему стекло |
|---|---|
| Плавающие панели управления над симуляцией | Контент виден сквозь панель, ощущение «панель над живым миром» |
| Таб-бар и таб-панель студии | Стандартное место стекла в iOS 26, навигация не отрезает контент |
| Нижние листы (настройки, пресеты, инструменты) | Видно, как симуляция реагирует на настройки сквозь лист |
| Карточка результата и прогресс экспорта | Праздничный, «премиальный» момент поверх последнего кадра |
| Разделитель и плашки текста в студии (опция для ролика) | Модный визуальный приём для роликов |

### Где не применяется (неуместно)

- Длинные списки и таблицы текста (настройки, лицензии, хранилище) — сплошной фон ради читаемости.
- Цены и кнопки покупки — сплошные контрастные поверхности (требование читаемости и честности цены).
- Системные диалоги (покупка, согласие, ATT, выбор видео) — их рисует система.

### Технические требования к материалу

| Свойство | Требование |
|---|---|
| Размытие фона | Двухпроходное Kawase/Dual-filter размытие сцены в буфере 1/4 разрешения, радиус 8–32 px. Буфер считается **один раз за кадр** для всех стеклянных элементов |
| Преломление | Смещение выборки фона по нормали к краю (карта нормалей скруглённого прямоугольника, вычисляется в шейдере по SDF), сила 0–12 px |
| Блик края | Тонкий светлый контур 1 px сверху-слева, затухающий по SDF; лёгкая реакция на гироскоп (± 4°, отключается при «Уменьшить движение») |
| Тонировка | Светлая/тёмная подложка 10–40% непрозрачности по теме |
| Контраст текста | Текст на стекле — WCAG AA (4,5:1) в худшем случае: если фон за панелью слишком яркий, подложка автоматически уплотняется (оценка средней яркости размытого буфера) |
| Стоимость | ≤ 1,5 мс GPU на кадр на тире B при 3 одновременных стеклянных элементах |
| Деградация | Тир C: размытие без преломления, буфер 1/8. «Уменьшить прозрачность» (системная настройка iOS `UIAccessibility.isReduceTransparencyEnabled`, на Android — собственный переключатель) → сплошные матовые поверхности 92% непрозрачности |

Спайк S3 (§11) подтверждает реализуемость и стоимость материала в выбранном UI-фреймворке до начала вёрстки экранов.

## 4.6. Жесты

| Жест | Где | Действие |
|---|---|---|
| Тап | везде | основное действие |
| Долгое нажатие | 🎲, карточки | доп. меню |
| Свайп вниз | нижние листы | закрыть / свернуть |
| Свайп по краю (системный «назад» Android, свайп от левого края iOS) | все экраны, кроме интерактивной игры | назад; в интерактивном режиме — пауза с подтверждением |
| Щипок / перетаскивание | слоты студии | масштаб и панорама видео |
| Двойной тап | слот студии | сброс масштаба |
| Перетаскивание | окно PiP | положение с «магнитами» |

## 4.7. Локализация

- Все строки — в таблицах локализации (Unity Localization, §7), ни одной строки в коде.
- **1.0: английский и русский** (по умолчанию — язык системы, иначе английский). Рекомендуемые следующие языки по размеру аудитории коротких видео: испанский, португальский (Бразилия), индонезийский, турецкий, немецкий, французский, японский, корейский, арабский (с RTL — отдельная задача) — вопрос В9.
- Вёрстка выдерживает удлинение строк на 40% (немецкий) без обрезки.
- Числа, даты, валюты — по локали устройства; цены — только из магазина (`localizedPrice`), никогда не форматируются вручную из долларов.
- Шаблоны текста для роликов локализованы отдельно от интерфейса (пользователь может делать ролик на английском при русском интерфейсе — переключатель языка шаблонов).

## 4.8. Доступность

| Требование | Реализация |
|---|---|
| Безопасные вспышки (US-20) | Переключатель **«Без резких вспышек»**: ограничение частоты смены яркости ≤ 3 раз в секунду, выключение стробоскопических эффектов финала, ограничение bloom. При первом запуске режима с интенсивными эффектами (M09, M11) — короткое предупреждение о фоточувствительности (один раз) |
| Уменьшить движение | Следует системной настройке (`UIAccessibility.isReduceMotionEnabled` / `Settings.Global.ANIMATOR_DURATION_SCALE = 0`): без параллакса, без пружин, мгновенные переходы. Симуляции не меняются — это контент |
| Уменьшить прозрачность | §4.5 |
| Цветовосприятие | Тема `Contrast` и опция «Узоры на шарах» (полоски, точки, звёзды) для режимов, где команды различаются цветом (M03, M06, M08) |
| Размер текста | Поддержка системного масштаба до 130% в интерфейсе |
| Экранные дикторы | VoiceOver/TalkBack: подписи у всех кнопок интерфейса (через нативный слой доступности — ограничение движков, §10, R12). Минимум 1.0 — основные кнопки и навигация озвучиваются |
| Тактильность | Отключаемая |
| Звук | Никакая информация не передаётся только звуком |
